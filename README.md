# Task Board

A simple to-do / kanban board that runs in your browser. Move work across To do, Doing, and Done, set due dates, and find tasks with search.

**Live app:** https://darenazhekbarovaboba-source.github.io/task-board/

## What it does

- Three columns: To do, Doing, and Done
- Drag and drop cards on a desktop
- Move buttons on every card, so it works on a phone too
- Optional due dates, with an overdue highlight for unfinished late tasks
- Search that filters the board by title
- Edit or delete any task
- Optional sample data so you can try it immediately

Your tasks are saved only in this browser with `localStorage`. There is no account and no server. Clearing site data will erase the board.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.
